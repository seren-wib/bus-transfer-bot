# 요구사항

## 목표

A→B 버스 경로에서, 타고 가는 노선의 중간 정류장을 전부 환승 후보로 놓고 실시간 도착으로 다시 계산해서, 허브 안에서 승강장을 옮기더라도 가장 빨리 도착하는 환승 지점을 찾는다.

## 문제 제기

앱은 환승 지점을 하나만 골라서 추천한다. 그 지점에서 실제 대기가 20분이어도 그대로 보여준다. 허브는 승강장 여러 개를 정류장 하나로 뭉갠다. 더 빠른 환승을 찾으려면 사람이 정류장마다 다시 검색하고 실시간을 따로 열어야 한다. 그 손 작업을 봇이 대신한다.

## 입력

`{출발지 A, 도착지 B, 출발시각 t}`

## 지도 앱 후보

네이버 지도, 구글맵, 카카오맵. 리허설에서 봇이 조작할 수 있는 앱 하나로 정한다. 아래에서 "지도 앱"은 정한 그 앱이다.

## 기능 요구사항

- **R1. 기본 경로 수집.** 지도 앱에서 A→B 대중교통 경로를 검색하고 1순위를 받는다. 탑승 노선 X, 승차 정류장 s0, 앱 추천 환승 정류장 s_app, 앱 예상 총 소요시간을 기록한다. 이것이 비교 기준값이다.
- **R2. 중간 정류장 목록.** 노선 X의 s0 이후 정류장 s1~sN과 A→si 예상 승차 시간을 노선 상세 페이지에서 뽑는다.
- **R3. 환승 후보 생성.** 각 si에 대해
  - 일반 정류장이면 si 하나.
  - 허브면 허브 안 승강장 전부. 허브 판정: 같은 이름 정류장이 여러 개 뜨거나 이름에 "환승센터", "환승정류장"이 들어간다.
  - 승강장마다 유형(광역/시내)을 붙인다.
- **R4. 후보별 si→B 검색.** 후보 승강장마다 B까지 대중교통 경로를 검색해 탑승 노선 Y, 예상 승차 시간을 받는다. 버스만, 추가 환승 없는 경로만.
- **R5. 실시간 도착 조회.** 후보 승강장에서 Y의 실시간 도착 예정 시간을 가져온다. 같은 방향 노선이 여럿이면 가장 빨리 오는 것을 쓴다.
- **R6. 총 소요 계산.** `총분 = A→si 승차 + 승강장 이동(허브면 1분, 아니면 0) + 실시간 대기 + si→B 승차`. 환승 횟수 패널티 없음.
- **R7. 추천.** 총분 최소 후보 하나. 출력은 `{추천 si, 승강장 유형, 환승 노선 Y, 대기 분, 총분, 앱 추천 s_app 총분, 단축 분}`과 사람이 읽는 한 줄.
  예: "사당역에서 내려서 광역 승강장으로 이동, M5107 타면 31분. 앱 추천(s7 환승)은 52분. 21분 단축."
- **R8. 비교 증거.** 앱 1순위보다 우리 추천이 빠른 케이스 1개 화면 캡처.
- **R9. 승강장 유형 분류.** 승강장에 서는 노선 색으로 광역(빨강)/시내(파랑·초록) 판정. 순위 계산에는 쓰지 않고 출력에만 쓴다.

## 비기능 요구사항

- **N1.** 지도 앱 조작은 봇이 한 번 직접 탐색한 뒤 Playwright 스크립트로 고정. 이후 실행은 스크립트만.
- **N2.** 검색 상한. 중간 정류장 최대 8개, 허브는 승강장 최대 4개. 합쳐서 검색 20번 이내. 리허설에서 검색 1회 시간을 재고 넘치면 정류장 수를 줄인다.
- **N3.** 검색 하나가 실패해도 전체는 죽지 않는다. 실패 후보는 빼고 계산.
- **N4.** A→B 한 번 처리 5분 이내.
- **N5.** 데모는 미리 돌린 결과 + 캡처. 실시간 시연은 백업.

## 범위 밖

지하철 · 환승 2회 이상(첫 환승만) · 허브 밖 도보 환승 · 이동 중 재계산 · 위치 추적 · 알림 연동 · 요금 · 혼잡도 · 막차

## 봇 분배

- **오케스트레이터 1개:** R1, R2 → s1~sN을 검색 봇 셋에 나눔 → 결과 모아서 R6, R7 → R8 캡처, 슬라이드.
- **검색 봇 3개 (같은 지시문):** 받은 si마다 R3, R4, R5, R9 → `results/{si}.json` 저장.
- 광화문까지 경로알려줘. -> 그록봇(1)작업내용수집, 다른 봇들에게 작업 할당() ->

## 봇 간 계약

- `tasks/bot{n}.json` = `[{si, 정류장ID, A→si분}]` — 오케스트레이터만 쓴다.
- `results/{si}.json` = `[{승강장, 유형, 노선Y, 실시간대기분, si→B분}]` — 검색 봇이 자기 si만 쓴다.

- 16:00까지 R8 캡처 1장.

## 리허설(11:20) 확인

- 지도 앱 경로 결과에 중간 정류장 목록이 나오는지 (R2)
- 실시간 도착이 경로 화면에 같이 뜨는지, 정류장 페이지를 따로 열어야 하는지 (R5)
- 허브 승강장이 따로 보이는지, 하나로 합쳐 보이는지 (R3)
- 검색 1회에 몇 초인지 (N2)
- 봇 셋이 브라우저를 따로 쓰는지
- gps 동의 필요, 네이버 지도 그록봇 조작여부 파악필요.
