# 진행 기록 (2026-11-01)

## 확정된 규칙
- 입력: "광화문 가고 싶어" → 현위치 GPS 좌표를 출발지로 사용
- 도보 속도 시속 5km (분당 약 83m)
- 환승 도보 500m까지 허용 (처음 30m → 500m로 변경)
- 환승 안전 단계 없음: 항상 가장 빠른 경로
- 첫 환승만 고려 (환승 2회 이상 범위 밖)
- 출력에 카카오맵·네이버 지도·구글맵 최적 경로를 함께 보여주고 비교. 우리 경로는 이들 중 최선보다 느리면 안 됨(그럴 땐 최선 경로를 그대로 추천)
- 추후 테스트: 임의 출발/도착 10쌍으로 타 지도 대비 우수성 측정 → 발표자료

## 리허설 (사당역 → 광화문, 네이버 지도)
- 자동 조작 차단·캡차 없음
- 중간 정류장 이름은 상세보기에 나오지만 화면엔 정류장별 시간 없음 (API에는 있음)
- 실시간 도착은 경로 화면 탑승 정류장에 같이 표시
- 허브 승강장은 정류장 번호별로 분리되어 표시 (사당역 18개+)
- 경로 검색 1회 약 1~1.3초
